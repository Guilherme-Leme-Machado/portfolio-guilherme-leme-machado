# 🔭 Astronomia e Exploração Espacial — Site com Bootstrap

## 📝 Descrição do Projeto
Este projeto consiste em um site multipáginas sobre **astronomia e
exploração espacial**, construído com o framework **Bootstrap 5**. O
objetivo é aproximar a ciência espacial do público geral, apresentando a
história da astronomia, a corrida espacial, os telescópios e as
descobertas recentes de forma visual e acessível.

Desenvolvido como parte das disciplinas de **Desenvolvimento Front-End
Para Web (2026.2)**, o site possui cinco páginas com barra de navegação
responsiva:

* **Home (`index.html`):** apresentação do propósito do site, carrossel
  com quatro temas (Sistema Solar, Missão Apollo, Telescópios e
  Descobertas Recentes) e seções de conteúdo com acordeões.
* **Dados (`dados.html`):** tabelas com estatísticas do Sistema Solar e
  dos principais telescópios, e um acordeão de perguntas frequentes.
* **Galeria (`galeria.html`):** linha do tempo ilustrada, com botões que
  abrem modais com detalhes de cada marco.
* **Sobre (`sobre.html`):** a história da astronomia, das estrelas
  antigas à corrida espacial e aos novos horizontes.
* **Contato (`contato.html`):** formulário com campos de texto, lista
  de assuntos, botões de opção, caixas de seleção e área de mensagem.

## 🚀 Tecnologias Utilizadas
* **Linguagem:** HTML5, CSS3 e JavaScript (via componentes do Bootstrap)
* **Bibliotecas:** Bootstrap 5.3 (CDN)
* **Ferramentas:** Git, GitHub e VSCode
* **Modelo de IA:** Gemini

## 📊 Resultados e Aprendizados
O projeto resultou em um site responsivo, com navegação consistente em
todas as páginas e vários componentes interativos do Bootstrap.

* **Sistema de Grid e Utilitários:** Usei `container`, colunas e classes
  utilitárias para espaçamento, cores e alinhamento, adaptando o layout a
  diferentes tamanhos de tela.
* **Componentes Interativos:** Apliquei navbar com menu retrátil,
  carrossel, acordeão e modais, sem escrever JavaScript próprio.
* **Tabelas e Formulários:** Estilizei tabelas (`table-striped`,
  `table-bordered`) e formulários com as classes `form-control`,
  `form-select` e `form-check`.
* **Organização de Conteúdo:** Aprendi a distribuir um conteúdo extenso
  em páginas com propósitos distintos e a conectar seções por âncoras.

## 🧠 Declaração de Uso Ético da IA
Este projeto utilizou inteligência artificial (Gemini) estritamente como ferramenta de suporte
tecnológico para pesquisa e redação dos textos sobre
astronomia e depuração de componentes do Bootstrap. Todo o código
gerado foi revisado, testado e compreendido por mim, garantindo a minha
responsabilidade integral sobre a autoria final, integridade e
funcionamento da aplicação.
