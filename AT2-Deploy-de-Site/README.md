# 🦷 Odontosite — Deploy de Site no GitHub Pages

## 📝 Descrição do Projeto
Este projeto consiste em um site institucional multipáginas para uma
clínica odontológica fictícia, a **Odontosite**, desenvolvido com HTML5
e CSS3 e publicado no **GitHub Pages**. O objetivo principal é percorrer
o ciclo completo de uma entrega web: criar as páginas, estilizá-las,
versionar o código com Git e colocá-lo no ar com um endereço público.

Desenvolvido como parte das disciplinas de **Desenvolvimento Front-End
Para Web (2026.2)**, o site possui cinco páginas com menu de navegação
fixo e indicação da página ativa:

* **Início (`index.html`):** chamada principal, resumo da clínica,
  destaques de tratamentos e especialidades e diferenciais.
* **Tratamentos (`tratamentos.html`):** limpeza, clareamento,
  ortodontia, implante, restauração e tratamento de canal.
* **Especialidades (`especialidades.html`):** oito áreas da odontologia,
  como Ortodontia, Implantodontia, Periodontia e Endodontia.
* **Sobre Nós (`sobre.html`):** missão, visão, valores e diferenciais.
* **Contato (`contato.html`):** formulário de contato e dados da clínica.

## 🚀 Tecnologias Utilizadas
* **Linguagem:** HTML5 e CSS3
* **Ferramentas:** Git, GitHub, GitHub Pages e VSCode
* **Modelo de IA:** Gemini

## 📊 Resultados e Aprendizados
O projeto resultou em um site de cinco páginas publicado e acessível por
um link público.

* **Layout com Flexbox:** Construí o cabeçalho fixo, o menu de navegação
  e os cartões (`cards`) usando `display: flex`.
* **CSS Compartilhado:** Centralizei o estilo em um único arquivo
  (`css/style.css`), reaproveitado por todas as páginas, com imagem de
  fundo e efeitos de `hover`.
* **Formulário HTML:** Criei um formulário com `label`, campos de texto,
  e-mail, telefone e área de mensagem.
* **Publicação:** Aprendi o fluxo de versionar com Git, enviar ao GitHub
  e ativar o GitHub Pages para disponibilizar o site online.

## 🧠 Declaração de Uso Ético da IA
Este projeto utilizou inteligência artificial (Gemini) estritamente como ferramenta de suporte
tecnológico para sugestão de textos das páginas e
depuração do CSS. Todo o código gerado foi revisado, testado e
compreendido por mim, garantindo a minha responsabilidade integral sobre
a autoria final, integridade e funcionamento da aplicação.
