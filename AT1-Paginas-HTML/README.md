# 🌐 Site Básico em HTML5 — Portfólio Pessoal

## 📝 Descrição do Projeto
Este projeto consiste na criação de uma página de portfólio pessoal
utilizando exclusivamente **HTML5 semântico**, sem CSS ou JavaScript. O
objetivo principal é praticar a estruturação de conteúdo web com as tags
corretas (`header`, `nav`, `main`, `section`, `article`, `address` e
`footer`), organizando as informações de apresentação pessoal em quatro
blocos: **Sobre**, **Formação**, **Experiência** e **Serviços**.

Desenvolvido como parte das disciplinas de **Desenvolvimento Front-End
Para Web (2026.2)**, a atividade conta com duas versões da página:

* `index.html`: versão inicial, feita manualmente, com a estrutura básica
  e textos de apoio nos blocos de conteúdo.
* `index_IA.html`: versão refinada com apoio de IA, com conteúdo
  completo, links de navegação por âncoras (`#sobre`, `#formacao`,
  `#experiencia`, `#servicos`), atributos de acessibilidade
  (`aria-label`, `aria-labelledby`), `meta description` e links
  `tel:` e `mailto:` no bloco de contato.

## 🚀 Tecnologias Utilizadas
* **Linguagem:** HTML5
* **Ferramentas:** Git, GitHub e VSCode
* **Modelo de IA:** ChatGPT

## 📊 Resultados e Aprendizados
O projeto resultou em uma página totalmente estruturada com HTML
semântico, com a comparação direta entre a versão manual e a versão
revisada com IA.

* **HTML Semântico:** Aprendi a diferenciar e aplicar corretamente as
  tags de seção, artigo, cabeçalho, navegação e rodapé.
* **Navegação por Âncoras:** Implementei um menu que leva a cada bloco
  da página por meio de `id` e links internos.
* **Acessibilidade Básica:** Conheci o uso de atributos `aria-*`,
  títulos hierárquicos (`h1` a `h3`) e idioma da página (`lang`).
* **Revisão Crítica:** Ao comparar as duas versões, identifiquei
  pontos de melhoria na minha própria estrutura, como a hierarquia de
  títulos e a falta de âncoras funcionais no menu.

## 🧠 Declaração de Uso Ético da IA
Este projeto utilizou inteligência artificial (ChatGPT) estritamente como ferramenta de suporte tecnológico
para a criação da versão aprimorada da página (`index_IA.html`),
servindo de comparativo com a versão desenvolvida manualmente
(`index.html`). Todo o código gerado foi revisado, testado e
compreendido por mim, garantindo a minha responsabilidade integral sobre
a autoria final, integridade e funcionamento da aplicação.
